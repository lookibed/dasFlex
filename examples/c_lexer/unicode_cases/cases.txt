# The Unicode case table of the C lexer example: each case is an input file of this folder and the
# token stream clang 18 lexes from it (clang -fsyntax-only -Xclang -dump-tokens, the default gnu17),
# with the verdicts of clang -fsyntax-only and gcc 11 -fsyntax-only (accept or reject, then the first
# error, or the first warning of an accepted file, as line:col). tests/c_lexer_unicode_tests.das
# lexes every input and compares; no compiler runs at test time.
#
#   case    the input is <name>.c
#   lexer   clang      - the lexer produces the clang stream: kinds mapped to the lexer's, each
#                        token's byte range equal
#           error N    - the clang tokens that start before byte N, each cut at N, then the lexer
#                        fails with its cursor at byte N (an `unknown` token in clang's stream, a
#                        character clang reports inside an identifier it keeps whole, or the quote
#                        of a literal holding an escape C11 6.4.4.4 does not list)
#           none ...   - out of scope for a lexer of preprocessed text, recorded only
#   tok     clang's kind, byte offset, byte length, spelling (bytes outside UTF-8 as \xNN)
